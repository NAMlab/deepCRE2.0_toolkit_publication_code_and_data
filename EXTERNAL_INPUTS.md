# External Inputs (`EXTERNAL/`)

All scripts and configs use paths relative to the **repository root**; run scripts from there unless their header specifies the web-app working directory. Large binary/intermediate files not stored in Git are written as `EXTERNAL/<category>/<file_or_dir>` (annotated with `# EXTERNAL (<category>): see EXTERNAL_INPUTS.md` in Python files). Place or symlink your files there, or update the path constants in the respective script/config.

| Category | What is needed | Where it is referenced |
|---|---|---|
| `EXTERNAL/cluster_scratch/` | Writable directory for SGE batch stdout/stderr logs (`$REPO/EXTERNAL/cluster_scratch/logs`). | All SGE job scripts in `code/02_training/{ssr,msr,ssc_control,tair10_exception}/` and `code/03_evaluation/crosspred_{deployed,msr}/` |
| `EXTERNAL/data_root/` | Root directory containing per-species unpacked genomes, Helixer annotations, and label CSVs (equivalent to `data/<species>/` once `gunzip` and `bash data/download_genomes.sh` have been run). Symlink `EXTERNAL/data_root/<name>` to `data/` or update the path constant. | `code/03_evaluation/s2v8_make_predict_config.1.py`, `code/06_annotation_frame/annotation_frame_runE.1.py` |
| `EXTERNAL/diamond/` | DIAMOND database files (`EXTERNAL/diamond/databases/*.dmnd`) and `blastp --outfmt 6` self-search tabular outputs per species (`EXTERNAL/diamond/BLASTdP_<sp>_to_<sp>`). Regenerate with `code/01_data_preparation/generate_diamond_commands.py` / `run_my_diamond_jobs.sh`. | `code/01_data_preparation/run_my_diamond_jobs.sh`, `code/01_data_preparation/validation_v8/species_config_v8.json` |
| `EXTERNAL/environment/` | Conda/Python 3.8 + TensorFlow 2.10 runtime matching `code/06_benchmarking/workflows/deepcre/pyproject.toml` (`$REPO/EXTERNAL/environment/conda.sh` and `$REPO/EXTERNAL/environment/deepCRE_p38tf210_gpu`, or `$REPO/EXTERNAL/environment/python`); replace with your local conda/venv path. | All SGE job scripts in `code/02_training/` and `code/03_evaluation/crosspred_*/`, plus `code/03_evaluation/run_s2v8_predict.0.sh` |
| `EXTERNAL/figure_inputs/` | Web-tool UI screenshots and Figure 1b base crop PNGs (`fig1_ab_crop.png`, `deepcre_random100_{predictions,explanation,mutation}.png`, `tutorial_canvas_10.png`) needed only when re-compositing Figure 1; not shipped in the repo. | `code/04_figures/build_updated_fig1.py`, `code/04_figures/make_pub_figures_split.7.py` |
| `EXTERNAL/figure_output/` | Writable output directory for rendered figures (`FIG_OUT_DIR` overrides this for `make_pub_figures_split.7.py` and derived scripts). | `code/04_figures/build_updated_fig1.py`, `code/04_figures/make_pub_figures_split.7.py` |
| `EXTERNAL/predictions/` | Raw per-gene CSV prediction outputs generated by `deepcre_predict` / `deepcre_crosspredict` (gigabytes of per-chromosome and cross-species prediction tables). Regenerate using deepCRE2.0 (`code/06_benchmarking/workflows/deepcre`) and the configs in `code/03_evaluation/{own_chromosome_configs,crosspred_deployed,crosspred_msr}`; their summarized metrics are committed in `results/evaluation/`. | `code/03_evaluation/s2v8_make_predict_config.1.py`, `code/03_evaluation/crosspred_deployed/configs/*.json`, `code/03_evaluation/crosspred_msr/configs/*.json`, `code/03_evaluation/own_chromosome_configs/own_chromosome_predict.json` |
| `EXTERNAL/refseq_gff/` | Compressed NCBI RefSeq GFF annotation files (`GCF_000001735.4_TAIR10.1_genomic.gff.gz` for *A. thaliana*, `GCF_902167145.1_Zm-B73-REFERENCE-NAM-5.0_genomic.gff.gz` for *Z. mays*) needed when re-running the annotation-frame comparison scripts (`Run B`, `Run D`; also required in `$RUNE_REFSEQ_DIR` for `Run E`). Download from NCBI Datasets alongside the `.fna` assemblies in `data/genomes.tsv`. | `code/06_annotation_frame/annotation_shift_runB.0.py`, `code/06_annotation_frame/annotation_shift_runD.0.py` |
| `EXTERNAL/sra_downloads/` | Default output directory for raw `.sra` archives fetched by the legacy 4-species `downloadExps.py` prototype (`downloadExps.1.py` accepts `<base_dir>` on the CLI). | `code/01_data_preparation/downloadExps.py` |
| `EXTERNAL/web_model_manifest/` | Table of the web-tool models (model id, species, tissue, model file), corresponding to `manifest.tsv` in `models/` of https://github.com/NAMlab/streamlit_deepcre_app; the model files are the deployed web-tool models. | All 11 `code/05_supplementary_figures/` inference/DeepSHAP scripts and 5 `code/06_annotation_frame/` scripts (`runA`–`runE`) |
