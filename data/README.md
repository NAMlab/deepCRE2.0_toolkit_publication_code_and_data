# Training Data, Annotations, Labels, and Validation Sets (`data/`)

This folder holds all genome annotations, expression matrices, binary classification labels, class-threshold diagnostic reports, Helixer proteomes, RNA-seq run metadata, and paralog-filtered validation gene pickles for the 13 angiosperm species in Peleke et al. (2026):

`arabidopsis_thaliana`, `beta_vulgaris`, `brassica_oleracea`, `camelina_sativa`, `chenopodium_quinoa`, `cucumis_sativus`, `daucus_carota`, `glycine_max`, `hordeum_vulgare`, `oryza_sativa`, `solanum_lycopersicum`, `sorghum_bicolor`, `zea_mays`.

---

## Shared Files in `data/`

| File | Purpose & Manuscript Role |
|---|---|
| `genomes.tsv` | Maps each species to its RefSeq genome accession (`GCF_*`), assembly name, Helixer GFF3 filename, and Helixer model (`land_plant_v0.3_a_0080`). |
| `download_genomes.sh` | Downloads the 13 RefSeq `.fna` genome FASTA files from NCBI into `data/<species>/genome/<accession>.fna` using NCBI `datasets` CLI. Run from any directory: `bash data/download_genomes.sh`. |
| `rnaseq_runs_used.tsv` | Exact manifest of the 154 SRA/ENA RNA-seq runs (leaf, root, shoot) quantified into the species TPM matrices, including `kallisto` version (0.50.1), read counts, `%` pseudoaligned, the exact `kallisto quant` command from `run_info.json`, and `in_SuppTable1` flag. |
| `rnaseq_runs.tsv` | Run table as compiled for Supplementary Table 1 (differs on 24 *A. thaliana*, *C. sativa*, *Cu. sativus*, *D. carota*, and *G. max* runs; `rnaseq_runs_used.tsv` is the exact provenance of what entered the TPM matrices). |
| `label_summary.tsv` | Summary of high (`1`), low (`0`), unused (`2`), total genes, zero-TPM fractions, and cut-off values across all 13 species × leaf/root. |
| `validation_set_dCRE2026.v8.p50c50e10.pickle` | Dictionary (`{species_code: [gene_id, ...]}`) of paralog-filtered validation genes (`v8` selection: identity `>= 50%`, reciprocal coverage `>= 50%`, `E <= 1e-10`, no inter-chromosomal paralogs, stratified by chromosome, seed 2026). Used for training early-stopping/checkpoint splits and Methods/Figure 2/Supplementary Figure 1 validation metrics. |
| `validation_set_dCRE2026.v8.p50c50e10.tair10.pickle` | *A. thaliana* validation gene IDs translated to TAIR10 locus space under key `"atha_tair10"` for the TAIR10 training exception (`code/02_training/tair10_exception/`). |

## Contents of Each `data/<species>/` Folder

| Pattern | Meaning |
|---|---|
| `*.helixer.gff.gz` / `hlx-*.gff.gz` | De novo Helixer gene models called on the RefSeq assembly (`land_plant_v0.3_a_0080`, md5 `f0e00efcbea83c66b69258d11119a691`). |
| `*.helixer.agat.gtf.gz` / `hlx-*.agat.gtf.gz` | Same Helixer annotation converted with AGAT v1.4.0; **used directly for 3,020 bp window extraction during training**. |
| `<Species>.<assembly>.59.gff3.gz` | Ensembl Plants release 59 annotation served to web-tool users for public gene IDs (Supplementary Table 1; see `code/06_annotation_frame/` for frame differences in *B. vulgaris*, *Cu. sativus*, and *G. max* where Ensembl assembly differs from RefSeq). |
| `<species>_tpm_matrix.csv.gz` | Gene × RNA-seq run kallisto TPM matrix (generated by `00_built_read_count_database_dPHY.0.py`; note: absent in `chenopodium_quinoa/` where only downstream normalized/labeled CSVs are stored). |
| `<species>_<tissue>_log10_mean_tpm_Q0.75_labeled_dPHYlogic.csv.gz` | Binary training targets (`target`: `1` = above 75th percentile of `log10(mean TPM + 1)`; `0` = equal-sized low-expression set with at most 50% zero-TPM genes and the lowest non-zero genes; `2` = intermediate/unused). |
| `label_reports/reports/*_classification_report.txt`, `label_reports/plots/*_classification_histogram.png` | Per-species/tissue class-threshold diagnostics generated by `make_label_reports_dPHYlogic_meanTPM.0.py`. |
| `*peptides*.fasta.gz` / `*proteome*.faa.gz` | Translated Helixer proteomes used for DIAMOND self-searches to exclude paralogous validation genes. |
| `SraRunTable_filtered_data_V3.csv` | Filtered SRA run metadata per species (`filterSRAs.py`; absent in `chenopodium_quinoa/` and `hordeum_vulgare/`, where full provenance is in `rnaseq_runs_used.tsv`). |

## Preparing Data for Training or Extending with a New Species

1. **Before training with `deepCRE_reimplemented`:** unpack compressed annotations/labels and fetch `.fna` assemblies:
   ```bash
   gunzip -k data/*/*.gz
   bash data/download_genomes.sh
   ```
2. **To add a new species:**
   * Add a row (`species\taccession\tassembly\thelixer_gff\thelixer_model`) to `data/genomes.tsv` and run `bash data/download_genomes.sh`.
   * Place `<species>_<tissue>_log10_mean_tpm_Q0.75_labeled_dPHYlogic.csv`, the `.agat.gtf`, and `.faa` files under `data/<species>/` using `code/01_data_preparation/` scripts.
   * Register the new species in `code/01_data_preparation/validation_v8/species_config_v8.json` and rebuild the validation pickle with `prepare_non_homologous_validation_sets_dPHY.8.py`.
